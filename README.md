# 🚀 Alperi Kelime Arama & Düzenleme Pro (V.4.0.0)

**Teknolojinin İyilikle Buluştuğu Nokta** Alperi Kelime Arama & Düzenleme Pro, karmaşık kod dosyalarından gelişmiş belgelere kadar binlerce satır veri içinde ışık hızında arama yapmanızı ve sonuçları anında düzenlemenizi sağlayan profesyonel bir Windows aracıdır.

Ancak bu yazılımın asıl gücü kodlarda değil, temsil ettiği umutta gizlidir. Bu proje, **DMD (Duchenne Musküler Distrofi)** hastası **Toprak Kaan Selvi**'nin dünyanın en pahalı gen tedavisine ulaşabilmesi için bir **sosyal sorumluluk projesi** olarak geliştirilmiştir.

## ✨ Özellikler

### 🟢 Ücretsiz Sürüm (Temel Özellikler)
* Metin dosyalarında (.txt, .js, .php, .css, .py, .html vb.) hızlı içerik araması.
* Alt klasörleri dahil ederek (recursive) geniş çaplı tarama.
* Dosya isimlerinde arama ve çoklu format filtreleme.

### 💎 Full Sürüm (Bağışçılar İçin Premium Özellikler)
* **Gelişmiş Format Desteği:** PDF, Word (.docx) ve Excel (.xlsx) dosyalarının *içeriğinde* doğrudan arama yapabilme.
* **Detaylı Satır Analizi:** Aranan kelimenin hangi sayfa, paragraf veya satırda bulunduğunu eşleşme sayısıyla birlikte görüntüleme.
* **Limitsiz Sonuç:** Dosya gösterme sınırını kaldırarak tüm sonuçlara erişim.
* **Dahili Metin Editörü:** Sağ tık menüsü ile dosyaları program içinden açma, düzenleme (Syntax highlighting destekli) ve kaydetme (Ctrl+H, Ctrl+G vb. kısayollarla).

# 🚀 Alperi Search & Edit Pro (V.4.0.0)

**Where Technology Meets Kindness** Alperi Search & Edit Pro is a professional Windows tool that allows you to search through thousands of lines of data at lightning speed—from complex code files to advanced documents—and edit the results instantly.

However, the true power of this software lies not in its code, but in the hope it represents. This software is developed as a **social responsibility project** to support **Toprak Kaan Selvi**, a child battling **DMD (Duchenne Muscular Dystrophy)**, in his fight to access life-saving gene therapy.

## ✨ Features

### 🟢 Free Version (Basic Features)
* Fast content search in text-based files (.txt, .js, .php, .css, .py, .html, etc.).
* Broad scanning by including subfolders (recursive search).
* File name search and multi-format filtering.

### 💎 Full Version (Premium Features for Donors)
* **Advanced Format Support:** Search directly *inside* the contents of PDF, Word (.docx), and Excel (.xlsx) files.
* **Detailed Line Analysis:** View exactly which page, paragraph, or line the searched word is located on, along with the match count.
* **Unlimited Results:** Removes the file display limit, giving you access to all found results.
* **Built-in Text Editor:** Open files directly within the program via the right-click menu, edit them (with Syntax highlighting support), and save (includes shortcuts like Ctrl+H, Ctrl+G).
