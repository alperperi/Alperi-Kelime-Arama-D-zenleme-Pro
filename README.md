# Alperi-Kelime-Arama-D-zenleme-Pro
Alperi Kelime Arama &amp; Düzenleme Pro, bilgisayarınızdaki binlerce dosya arasında kaybolmanızı engelleyen, yüksek performanslı bir Windows kelime arama ve metin düzenleme yazılımıdır. Bu program sadece iş akışınızı hızlandırmakla kalmaz; her lisans aktivasyonuyla DMD Kas Hastalığı ile savaşan Toprak Kaan Selvi'nin kahramanı olmanızı sağlar.
